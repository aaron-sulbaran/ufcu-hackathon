Trust is layered

Not gated

Paths

  • SSN
  • ITIN
  • Foreign status (passport + W-8BEN)

Two stages → confidence

  • Stage 1, from the details: data consistency, watchlist, taxpayer number match
  • Stage 2, only if stage 1 cannot match: government ID plus selfie, the step-up large banks run; placeholder for a third-party vendor

Three routes

  • Instant
  • Video with a banker
  • Branch visit
The CIP rule requires name, date of birth, address, and an ID number before an account opens; it governs what is collected, not the order a website asks for it. We collect it all, with the reason next to each field, after the person has decided.
Simulated today; maps to a KYC vendor and the core in production.
